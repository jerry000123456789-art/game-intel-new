# 全球遊戲情報中心（全新專案）

第一階段：純靜態 GitHub Pages 網站，無需付費伺服器。

## 部署
1. 在 GitHub 建立新的 **Public** repository，例如 `game-intel-new`。
2. 將本資料夾的 `index.html` 上傳到 repository 根目錄，提交變更。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**，資料夾選 **/(root)**，按 Save。
4. 等待 Pages 部署完成後，開啟 `https://你的帳號.github.io/game-intel-new/`。

## 注意
目前四個分區的資料均為示意，不代表真實上市、儲值、兌換碼或活動資訊。後續再增加自動資料蒐集與驗證。
